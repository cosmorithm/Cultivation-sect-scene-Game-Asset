# Three.js 模型与交互预览

A02 至 I12 的每个资产目录有一个可编辑的 `ThreeJS/model.mjs`。它导出 `buildAsset(THREE)`，生成以米为单位、Y 轴向上的独立模型。相近构件的建模函数放在本目录。动画随模型作为 glTF 动画片段导出。天空、光照和雾的模型用于演示效果。

双击资产目录的 `交互预览.html` 可以离线旋转、平移、缩放和存图。页面含全景、背侧和俯视三个镜头。带动画的资产可以暂停和播放。目录中的三个 PNG 是从交付的 GLB 加载后使用 Three.js 渲染得到的。

## 重新构建

在本目录使用 Node.js 18 或以上版本运行以下命令。可用其他资产编号替换 A02 和 A03。

```sh
npm ci
npm run build -- A02 A03
```

构建脚本把 GLB 和离线 HTML 写回对应目录。模型造型取自三视图与效果示意，缺少实测尺寸的部分按场景用途估算。模型用于外观和组合评审。碰撞、LOD、Unity 项目中的灯光、粒子系统与目标设备性能由使用项目配置。

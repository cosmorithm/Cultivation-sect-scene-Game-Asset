# A01 主殿模型样件

双击上一级目录的《A01_主殿_交互预览.html》可以离线查看模型。拖动旋转，滚轮缩放。全景、阶前仰视和门廊近看共用同一份 Three.js 几何和材质。上一级的三个 PNG 取自这三个视角。

## 修改和导出

在本目录使用 Node.js 18 或更新版本运行以下命令。

```sh
npm ci
npm run build
npm run preview:build
```

第一个构建命令生成上一级的 `A01_MainHall.glb`。第二个构建命令更新独立 HTML。两者使用相同的 `roof.mjs`、`timber.mjs`、`stone.mjs` 和 `materials.mjs`。修改预览光照与镜头可编辑 `viewer.mjs`。

## 尺度和验证

样件以米建模，原点在台基地面的中心，Y 轴向上，入口朝正 Z。依照已有配色稿推定整体尺寸，含正阶的包围盒宽约 53.94 米、深 46.65 米、高 28.24 米。模型有 65 个网格、365,812 个三角面。GLB 内含材质和贴图。全景的地面、灯光和相机由预览页添加。

Khronos glTF Validator 对此版报告 0 个错误、0 个警告。此版用于外观评审，碰撞、LOD、室内及目标设备的渲染性能仍待处理。Unity 编辑器的测试启动停在共享内存初始化步骤，glTFast 的实际导入效果待验证。
